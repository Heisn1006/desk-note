# DeskNote · 悬浮桌面便签

贴在桌面上的小卡片，显示最近的日程、任务和截止倒计时。

## 仓库结构

| 路径 | 内容 |
| --- | --- |
| 根目录 | `main.js`、`preload.js`、`renderer/`、`lib/`、`bin/` —— 便签本体与插件宿主 |
| `dev/` | 测试与构建：`dev/check-all.cmd`、`dev/tools/*`（node 测试、冒烟、发版脚本、C# 工具源码） |
| `plugins/` | 插件运行时槽位：只留 `lock.json` + `README.md`，插件源码**不在本仓库** |
| `dist/` | 打包产物（不入库） |

插件本体在独立仓库 **https://github.com/Heisn1006/desk-note-plugins** （壁纸穿透及其探测工具）。
构建/打包前先拉插件：`node dev\tools\fetch-plugins.mjs`（离线可用 `--from ..\desk-note-plugins`）。
安装包里仍然内置插件，用户端不需要下载。

## 怎么打开

- **桌面快捷方式**：`DeskNote 便签`（双击即可，不会弹黑框）
- 或双击 `dev\launch.vbs`（从仓库源码跑，不装安装包时用）

## 怎么用

| 操作 | 效果 |
| --- | --- |
| 点 `+` | 打开编辑器：任务名 / 截止日期+时间 / 最迟开始日期+时间 / 每周重复 |
| **右键任意任务** | 重新打开编辑器，改标题、截止、最迟开始、重复 |
| 点左侧圆圈 | 标记完成 / 取消完成（每周任务完成后到点自动回到待办） |
| 点 `∧` | 收起为迷你条；鼠标移上去自动展开 |
| 点 `×` | 退出程序 |
| 点 `⚙` | 设置：语言 / 皮肤 / 背景 / 缩放 / 显隐快捷键 / 插件 / 自启 / 全屏 / 页脚 / 数据 |
| 设置 → 语言 | 简体中文 / 繁體中文 / English，即时切换，只换界面文案，**不动你写的任务标题** |
| 设置 → 数据 | 导出 JSON 备份 / 导入 JSON（只加新任务，不覆盖、不删除已有任务） |
| `Ctrl + Alt + N` | 全局显示 / 隐藏（可在设置里改） |

## 键盘操作

| 按键 | 效果 |
| --- | --- |
| `↑` / `↓` | 在任务之间移动选中（按列表显示顺序） |
| `空格` | 完成 / 取消完成选中的任务 |
| `Enter` | 编辑选中的任务 |
| `Delete` | 删除选中的任务 |
| `Esc` | 依次关掉编辑器 → 设置面板 → 隐藏窗口，同时清掉选中 |

设置面板打开、正在输入、或迷你条状态下，方向键/空格/Delete 不会误操作任务。

## 安装与升级

- 安装包解压后双击 **`install.exe`**；卸载双击 **`uninstall.exe`**（或开始菜单）。
- 升级时安装程序会**替换旧程序文件**（旧版本多出来的文件会删掉），只保留
  `DeskNoteData\` 里的任务、设置和备份。

## 页脚

- 设置 → 页脚：可以改右下角的文案、选字体、开关斜体。
- 字号固定为比原来稍大一档、默认加粗；文案太长会自动换行，底栏向上变高，不影响窗口尺寸。

## 插件

- 设置 → 插件 → 插件管理：开关立即生效，垃圾桶卸载插件（删除插件文件）。
- 内置插件「壁纸穿透」：把桌面壁纸按真实位置映射到便签背景，窗口移动时壁纸跟着走，换壁纸自动更新（源码在 [desk-note-plugins](https://github.com/Heisn1006/desk-note-plugins)）。
  静态壁纸直接读注册表；Wallpaper Engine 项目支持 **.mp4 / .webm 视频壁纸**（自动循环播放），场景（scene.pkg）、网页（index.html）等其它类型只显示项目自带的 preview 图 —— 这类壁纸没有可直接播放的媒体文件，不打算为它做引擎重绘，插件设置里也写了这条限制。
- 壁纸穿透和自定义背景**互斥**：开启壁纸时背景按钮会被禁用，关掉后自定义背景恢复。
- 插件放在程序目录 `plugins\<id>\`，一个 `plugin.json` + 一个 `index.js` 即可；宿主只认这个约定，不关心插件来自哪个仓库。

## 全屏

- 默认开启「全屏时自动隐藏」：检测到有全屏应用（游戏/视频）在前台时，便签自动隐藏；
  退出全屏后自动回来。可在设置里关闭。

## 背景图

- 设置 → 背景 → **选择图片**：选好后进入裁切面板。
- **拖动**画面调整取景位置，**滚轮**缩放（1–3 倍）。
- **浓度**：背景蒙版的浓淡（20%–100%）。越淡图片越清楚，越浓文字越好读。
- **取消**不会替换原来的背景；点**确定**才保存。
- 清除背景会顺带删掉复制到 `DeskNoteData` 的那张图片，不会留垃圾文件。

## 提醒规则

- **最迟开始 → 截止**：这段区间内每天提醒一次（列表 🔔 + 顶部提醒条 + 每天一条系统通知）。
- 没设最迟开始：从截止之后开始提醒，直到标记完成。
- 每周任务：完成后进入「已完成」，到下一次的时间自动重置回待办。

## 时间规则

- 任务时间存的是**本地日期 + 时分**，按系统时钟判断，不联网校时。
- 一次性任务：是一个绝对时刻，**不会**因为到了明年同一天而重新出现；没完成就一直显示「已逾期 N 天」。
- 每周任务：过期后按「星期几 + 时分」滚到**现在之后**最近的一次；放一年不管，也只会落到本周/下周，不会停在去年的日期。
- 已完成且跨过 `nextAt` 的每周任务：启动时先重置、再滚到本周（离线一年也一样）。

## 数据

- 任务存在程序目录下的 `DeskNoteData/state.json`（升级/重装不会覆盖）。
- 每天第一次保存前会在 `DeskNoteData/backups/` 留一份 `state-YYYYMMDD.json`，只保留最近 7 天。
- 导出 / 导入在 设置 → 数据；导出文件是可读 JSON，导入只新增不覆盖。
- 纯本地、不联网：CSP 限制为 `default-src 'self'`，没有任何 fetch/XHR/外链资源。

被 Windows 拦住与联网无关，是 SmartScreen 对「未签名 exe + 网络下载标记（Mark-of-the-Web）」的判定。
已用 `Unblock-File` 解除该标记；若仍提示，点「更多信息 → 仍要运行」一次即可，系统会记住。

## 多显示器

- 窗口位置按显示器保存（`displayId`），换屏/拔屏/改缩放后会拉回可见区，至少保留 140×80 像素。
- 允许跨屏摆放，不会被强行拽回主屏。

## 开机自启

已写入注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`（值名 `DeskNote`），
指向 `wscript.exe launch.vbs`，所以开机时静默启动、不弹控制台。

不想自启就删掉这个注册表值，或在托盘菜单里取消勾选。

## 技术说明

Electron 45 + 原生 HTML/CSS/JS，无框架、无构建步骤。
界面文案在 `renderer/i18n.js`（主进程与渲染进程共用一份），时间滚动规则在 `renderer/schedule.js`，
导入导出、备份轮转、多显示器几何在 `lib/`。

当前环境里 Chromium 多进程会被拦，所以启动参数带了 `--no-sandbox --disable-gpu`。

## 检查更新

设置面板底部显示当前版本，旁边是「检查更新」。

- 启动 5 秒后会自动静默检查一次，发现新版本会在便签里弹一次提示，按钮变成「下载 vX.Y.Z」；
- 手动点「检查更新」：已是最新会提示版本号，有新版本会直接用浏览器打开下载页；
- 检查对象是一份静态 `version.json`，**只做提示，不自动下载、不自动安装**。

`version.json` 长这样（放在仓库根目录即可）：

```json
{
  "version": "0.2.14",
  "url": "https://github.com/<你的用户名>/desk-note/releases/latest",
  "notes": "这一版改了什么"
}
```

清单地址在 `main.js` 的 `updateManifestUrl()` 里，形如
`https://api.github.com/repos/<用户名>/<仓库>/contents/version.json`。

> 用 **api.github.com 的 contents 接口**、并带 `Accept: application/vnd.github.raw`，是因为 `raw.githubusercontent.com` 和 `cdn.jsdelivr.net` 在很多网络（尤其国内）会被重置；实测本机 raw 是 000、api 是 200。

调试时可以用环境变量 `DESKNOTE_UPDATE_URL` 指向本地文件或任意 http 地址，不用改动代码。
